# 留迹独立镜像发布

## 用户目标
使用已配置的 Docker Hub Secret 发布留迹的开源容器镜像。

## 沟通结论
复用本仓库现有 Secret，仅在独立分支增加专用工作流，固定检出留迹已公开提交，不修改雅思工具业务。项目简介统一为“Docker自部署时间轴笔记工具，可快速导出为截图。”。

## 实施记录
新增 liuji.yml，验证留迹源码后构建 amd64、arm64 并发布 1.1.0 与 latest；同一任务更新 Docker Hub 简介与 README。

## 验证结果
留迹本地 12 项测试、语法、构建和公开文件检查通过。镜像发布结果以 Actions 实际状态为准。

## 教程提炼
凭据不离开 GitHub Actions；外部源码固定完整提交，检出不持久化 GitHub 凭据。

## 隐私检查
不导出 Secret、令牌或运行数据，只提交公开项目地址和 CI 配置。
