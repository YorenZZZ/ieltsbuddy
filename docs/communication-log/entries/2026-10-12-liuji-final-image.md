# 留迹首发镜像固定源码

## 用户目标
发布带页面示例、统一简介、草稿直接删除和按钮反馈的留迹镜像。

## 沟通结论
继续使用已有 Docker Hub 发布凭据，只发布留迹独立镜像。

## 实施记录
工作流固定到留迹已公开的最终源码提交，OCI 标题改为留迹；成功推送镜像后同步 Docker Hub 简介与完整 README。

## 验证结果
首次运行在依赖安装时失败。留迹修复锁文件后已通过清洁安装、13 项测试和生产构建；本次多架构镜像结果以新的 Actions 运行记录为准。

## 教程提炼
跨仓库发布必须固定已验证的源码提交，失败不能描述为发布成功。

## 隐私检查
凭据仅在 CI 中引用已有 Secret，没有导出或写入源码。
